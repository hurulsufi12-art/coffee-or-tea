# One Letter: Coffee or Tea

One letter — **A** for coffee.

`main.py` (Python 3.13, stdlib only) writes exactly one letter to `/output/entry.txt`: `A`, the answer to "coffee or tea?". Deterministic: the same letter on every run.

Why coffee: of the judge's criteria, coffee is the more vivid answer (morning jolt, bitterness, steam, caffeine rush — "but first, coffee"), the funnier one (caffeine-addiction wit), and the truer one (the louder, more committed stance). Tea is calm and polite by comparison.
